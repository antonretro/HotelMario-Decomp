WHAT IS THIS?

A project to rebuild the source code of Hotel Mario (Fantasy Factory / Philips, 1994) so that it compiles back into the exact same program, byte for byte. Each door is one function from the game's original symbol table. The game is about closing doors, so a door closes when its function is rewritten in C.

When the code is decompiled, it can be ported to PC, 3DS and Wii.

HOW IT WORKS

  1. Read the CD-i disc (CD-RTOS filesystem) from your own disc image
  2. Split the OS-9 program cdi_hotel into functions using the original .stb symbols
  3. Rebuild with vasm + the OS-9 module CRC and check the SHA1
  4. Swap functions from assembly to C one at a time, keeping the build matching

No game data is stored in the repository.
