BIOS-free port

A side project next to the decomp. The game's main program is translated from 68000 machine code into C and runs on PC; the code it streams from the disc runs on a built-in 68000 interpreter. No CD-i BIOS needed.

Not playable yet. It now boots by itself through the Philips logo, the Fantasy Factory logo and the whole intro cartoon to the title screen, with the Philips jingle, the intro speech and the title music. The attract demo starts after a while.

Gameplay, menus with input, and in-game music and sound effects are next.

Want to play Hotel Mario natively today? See cdirecomp by mstan, a separate CD-i static recompiler that runs it using a CD-i system ROM.

What is this?

A matching decompilation

A project to rebuild the source code of Hotel Mario (Fantasy Factory / Philips, 1994) so that it compiles back into the exact same program, byte for byte. Each function is rewritten as K&R C for Microware's OS-9/68000 C compiler, the one the game was built with.

Once the code is decompiled, it can be ported to PC, 3DS and Wii.

How it works

  1. Read the CD-i disc (CD-RTOS filesystem) from your own disc image
  2. Split the OS-9 program cdi_hotel into functions using the original .stb symbols
  3. Rebuild with vasm plus the OS-9 module CRC and check the SHA1
  4. Swap functions from assembly to C one at a time, keeping the build matching
